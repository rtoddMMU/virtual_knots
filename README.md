# Virtual Knot Theory Package

Python package for computing gl(n|m) invariants of virtual knots using the Chrisman-Podel framework.

## Features

- Virtual knot representations (Gauss codes, planar diagrams)
- Reidemeister moves (classical, virtual, and mixed)
- Bartholomew's algorithm for braid representation
- gl(n|m) invariant computation
- Batch processing for large knot tables
